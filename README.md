# Spoti Skipper 🎤⏭

Голосовое управление Spotify через [Spicetify](https://spicetify.app). Говоришь «Джарвис, некст», и трек скипается. Распознавание работает **офлайн** (Vosk), ничего никуда не отправляется.

## Как устроено

```
микрофон ─► listener.py (Vosk, офлайн) ─► ws://127.0.0.1:8974 ─► spoti-skipper.js (внутри Spotify) ─► Spicetify.Player
```

Почему не распознавание прямо в Spotify: встроенный в Chromium Web Speech API внутри клиента Spotify не работает (нет ключей Google), поэтому речь распознаёт маленький локальный слушатель.

## Установка (Windows)

Нужно: Spotify + [Spicetify](https://spicetify.app/docs/getting-started), Python 3.9+.

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт копирует расширение в Spicetify, делает `spicetify apply` и ставит Python-зависимости в `listener\.venv`.

Потом запусти **`start.bat`**. При первом запуске скачается русская модель Vosk (~45 МБ). В Spotify появится уведомление «голосовое управление включено».

<details><summary>Вручную / macOS / Linux</summary>

```bash
cp extension/spoti-skipper.js "$(spicetify path userdata)/Extensions/"
spicetify config extensions spoti-skipper.js && spicetify apply
cd listener && python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python listener.py
```
</details>

## Команды

Сначала **«Джарвис»** (или *Jarvis*), потом команда, всё в одной фразе. Порядок свободный, лишние слова не мешают: «Джарвис, пожалуйста, пропусти эту песню».

| Действие | Примеры (полный список в `listener/commands.json`) |
|---|---|
| ⏭ Следующий | некст, дальше, скипни, пропусти, переключи, давай другую, следующую песню, мимо, не нравится, next, skip |
| ⏮ Предыдущий | назад, верни, обратно, прошлую песню, предыдущий трек, back, previous |
| ⏪ Сначала | сначала, заново, повтори песню, включи сначала, restart |
| ⏸ Пауза | пауза, на паузу, стоп, хватит, выключи музыку, pause |
| ▶ Играть | играй, продолжи, включи музыку, сними с паузы, погнали, play |
| 🔊 / 🔉 Громкость ±10% | громче, погромче, прибавь звук / тише, потише, убавь звук |
| ❤ В любимые | лайкни, лайкни эту песню, поставь лайк, мне нравится, сохрани, добавь в избранное / в любимые / в фавориты |
| 🤍 Убрать из любимых | убери лайк, сними лайк, дизлайк, убери из избранного / из любимых / из фаворитов |
| 🔀 Перемешать | перемешай, вперемешку, случайный порядок, shuffle |
| 🔁 Повтор | повтор, на повтор, зацикли, repeat |

«Лайкни» только ставит лайк, а «убери лайк» только снимает: повторная команда ничего не сломает.

### Как поменять слова

Открой **`listener/commands.json`** и правь списки: можно добавлять фразы из нескольких слов, писать строчными и без запятых. Там же `wake_words`, варианты «Джарвиса» (модель может услышать его как «джервис» или «жарвис»). После правки перезапусти `start.bat`.

Чтобы узнать, как модель слышит твоё слово, запусти **`start.bat --debug`**: в консоли будет печататься всё распознанное. Если «некст» слышится как, например, «нэкс», допиши этот вариант в `commands.json`.

## Настройка: `listener/config.json`

| Поле | Что это |
|---|---|
| `require_wake_word` | `false`: команды без «Джарвис» (но тогда их может «сказать» сама песня из колонок) |
| `min_conf` | порог уверенности распознавания 0–1 |
| `fuzzy` | насколько похожим должно быть слово (0.8 по умолчанию; `1.0`: только точные совпадения). Ложные срабатывания → подними |
| `lang` | `ru` или `en-us` |
| `device` | номер микрофона (`start.bat --list-devices`) |
| `extra_commands` | свои фразы поверх commands.json: `{"next": ["врубай следующий"]}` |
| `port` | порт WebSocket. Если меняешь, в консоли Spotify (Ctrl+Shift+I): `localStorage.setItem("spoti-skipper:port", "9000")` |

## Проверка без микрофона

```
start.bat --keyboard
```
и вводи `next`, `пауза`, `лайкни эту песню`: команды уйдут в Spotify.
